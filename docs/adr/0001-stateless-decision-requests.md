# Stateless one-shot Decision Requests to the Opponent Agent

The opponent is whichever coding-agent CLI the user has installed (Claude Code, Codex, Gemini CLI, ...), so the integration must work identically across CLIs we don't control. We decided every agent decision is a fresh, self-contained one-shot invocation (prompt in, JSON action out) rather than a persistent conversation/session. Persistent sessions would give the agent free memory, but session mechanics differ per CLI and break between versions; instead, continuity comes from the game itself compiling a Match Digest into every request. The agent must reply in strict JSON; unusable output gets one retry, then a forced Fallback Action (check if legal, else fold), so a match can never stall on a misbehaving agent.
