# Key Hint Rows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show a bottom key-hint row during the agent's turn (`> (t)alk`) and at hand end (`> (enter) next hand  (t)alk`), and strip the redundant "enter for next hand" from the banner.

**Architecture:** Two new cases in `View`'s bottom phase switch in `internal/tui/app.go`; two banner strings in `finishHand` lose their suffix. Nothing else changes.

**Tech Stack:** Go, Bubble Tea (existing deps only).

Spec: `docs/superpowers/specs/2026-07-03-key-hints-design.md`

## Global Constraints

- Hint row format exactly: agent turn `  > (t)alk`; hand end `  > (enter) next hand  (t)alk` (two spaces between items, matching the your-turn row's `strings.Join(opts, "  ")` spacing).
- No hint row in `phaseRunout`; `phaseMatchOver` keeps its existing footer.
- Hints render in quiet mode too.
- Existing tests must keep passing unchanged.

- [ ] **Step 1: Write the failing test**

Add to `internal/tui/app_test.go`:

```go
func TestKeyHintRows(t *testing.T) {
	m := testModel(t)
	m2, _ := m.Update(startHandMsg{})
	m = m2.(Model)
	m2, _ = m.Update(key("c")) // human limps -> agent turn
	m = m2.(Model)
	if m.phase != phaseAgentTurn {
		t.Fatalf("phase = %v, want phaseAgentTurn", m.phase)
	}
	if !strings.Contains(stripANSI(m.View()), "> (t)alk") {
		t.Error("agent-turn view missing talk hint row")
	}

	m = testModel(t)
	m2, _ = m.Update(startHandMsg{})
	m = m2.(Model)
	m2, _ = m.Update(key("f")) // fold -> hand end
	m = m2.(Model)
	if m.phase != phaseHandEnd {
		t.Fatalf("phase = %v, want phaseHandEnd", m.phase)
	}
	view := stripANSI(m.View())
	if !strings.Contains(view, "> (enter) next hand  (t)alk") {
		t.Error("hand-end view missing key hint row")
	}
	if strings.Contains(view, "enter for next hand") {
		t.Error("banner still contains redundant 'enter for next hand'")
	}
}
```
